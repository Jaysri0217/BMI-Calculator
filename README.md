# BMI Calculator 🧮

A simple and user-friendly **BMI (Body Mass Index) Calculator** that calculates a person's BMI based on their height and weight and displays the corresponding BMI category.

## 📌 About the Project

The BMI Calculator is a web-based application designed to help users quickly calculate their Body Mass Index.

The user enters their **height** and **weight**, and the application calculates BMI using the standard formula:

**BMI = Weight (kg) / Height² (m²)**

Based on the calculated BMI value, the application displays the user's BMI category.

## ✨ Features

* Calculate BMI quickly and easily
* Simple and clean user interface
* Accepts height and weight as input
* Displays the calculated BMI
* Shows the corresponding BMI category
* User-friendly design
* Works directly in a web browser

## 📊 BMI Categories

| BMI Range      | Category      |
| -------------- | ------------- |
| Below 18.5     | Underweight   |
| 18.5 – 24.9    | Normal Weight |
| 25.0 – 29.9    | Overweight    |
| 30.0 and above | Obesity       |

> **Note:** BMI is a general screening measure and does not directly measure body fat or overall health.

```bash

```

2. Open the project folder.

3. Open the `index.html` file in any modern web browser.

4. Enter your height and weight.

5. Click the calculate button to view your BMI result.

## 🧮 How It Works

1. The user enters their height and weight.
2. The application collects the input values using JavaScript.
3. Height is converted into meters if required.
4. BMI is calculated using:

```text
BMI = Weight / (Height × Height)
```

5. The calculated BMI is compared with standard BMI ranges.
6. The appropriate BMI category is displayed to the user.
